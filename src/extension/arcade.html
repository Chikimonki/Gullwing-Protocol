🎮 Gullwing Arcade

📖 How to Play

You don't need to know assembly. Each level has a goal (like "return the number 42").

1️⃣ Click 💡 Show Solution to see working code.
2️⃣ Click ▶ Submit to compile it and run Gullwing analysis.
3️⃣ Click 🔬 See Analysis to view the raw evidence JSON that Gullwing produces.

What you're learning: Every submission becomes a real ELF binary that Gullwing analyzes through all 8 layers — identity, structure, semantics, entropy, ML classification, runtime, memory, and convergence. The same analysis that detects supply chain attacks on production systems is now analyzing code YOU control.

Par = the optimal number of instructions. Fewer is better. But functional is the goal — optimization comes later.
