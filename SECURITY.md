# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Gullwing Protocol, please report it responsibly.

**Do NOT open a public issue.**

Instead, email: forgottennord@gmail.com

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **24 hours:** Acknowledgment of receipt
- **72 hours:** Initial assessment
- **7 days:** Fix or mitigation plan
- **30 days:** Public disclosure (after fix)

## Supported Versions

| Version | Supported |
|---------|-----------|
| 5.1.0+ | ✅ Yes |
| < 5.1.0 | ❌ No |

## Security Best Practices

1. Always verify SHA-256 hashes
2. Run Gullwing in air-gapped mode for critical systems
3. Keep the ML model updated
4. Review quarantine logs regularly
